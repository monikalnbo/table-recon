# 02 · 双表核对图形界面

单文件网页（`index.html`），浏览器直接打开即用，**数据不出本机**。这是离线路径；AI 核对走 pi + excel MCP + table-recon MCP（见根 README / `01-minimal-pi`）。

## 功能

- 拖入/点击上传两份表格（xlsx / xls / csv）
- 各自下拉选择关联列（自动按"订单/单号/编号"智能预选）
- 动态添加核对规则：**区间**（A列范围 包含 B列值）/ **精确**（两列一致），每条规则可设容差与裸数单位
- 结果统计卡片 + 四个分栏（区间不符 / 项不一致 / 仅A方 / 仅B方）
- 一键导出标红报告 `核对报告.xlsx`（总览 + 异常清单 + A/B方整行标红标注，ExcelJS 生成）

## 单位说明

值带单位（`800g` / `0.5-1kg` / `2~2.5公斤`）自动换算后比较；
纯数字按规则行里选的"裸数单位"（缺省 kg）理解，A/B 两侧可分别设置。

## 与命令行结果一致性

页面内嵌的 JS 引擎与 `core/recon.py` 逻辑同源，同一份测试数据两边核对结果一致
（见根 README）。
