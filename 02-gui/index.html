📊 双表核对工具

指定关联列（如订单号）+ 自定义核对规则（区间包含 / 精确一致），本地浏览器内完成，数据不上传。导出标红 Excel 报告。

A 方（区间规则里 = 范围一方）

点击或拖入 A 方 表格（.xlsx / .xls / .csv）

B 方（区间规则里 = 具体值一方）

点击或拖入 B 方 表格（.xlsx / .xls / .csv）

核对规则

区间 range：A方该列是范围（0.5-1kg / 500-800g / 小于1 / 2以上），B方是具体值；B值不在A范围内 = 异常。 精确 exact：两列必须完全一致（数值按值、文本忽略大小写空格）。 单位自动换算 g/kg/公斤/吨/lb；"裸数单位"用于该列没写单位的数字。
